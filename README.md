# UniPocket

UniPocket 是給大學生使用的課表、工作帳務與個人財務管理 PWA。它把一週課表、家教與工作安排、收支記帳，以及好友之間的課表與帳務互動集中在同一個介面中，適合在手機或桌面瀏覽器使用。

## 功能

### 課表與行程

- 以週曆查看課表，支援上週、下週、本週與指定日期跳轉。
- 新增多個學期或自訂課表，設定學期日期與每節課時間。
- 新增一般課程、家教、工作與臨時事件。
- 支援臨時調課、課程備註、死線提醒與 12/24 小時制。
- 內建學分計算機，可依學期與課程類型追蹤修課學分。
- 可查看已連線好友的課表，並標示雙方空堂交集。

### 家教與工作帳務

- 分開管理家教帳務與工作帳務。
- 記錄日期、對象、時數、金額、付款狀態與備註。
- 依月份或全期間篩選，並可切換新到舊或舊到新的排序。
- 顯示總時數、預計收入、未收款與個別學生統計。

### 個人財務

- 記錄收入、支出、轉帳、應收款與應付款。
- 支援主類別與子類別、自訂分類、分類排序與隱藏紀錄。
- 依月份篩選，查看總收入、總支出、淨結餘、總應收與總應付。
- 以圖表查看支出或收入的分類比例。
- 支援週期性記帳與還款紀錄。
- 與好友共享借款、代墊、還款、修改及刪除請求，需由對方確認後同步。

### 帳號、同步與外觀

- 可使用 Supabase Email/Password 登入或註冊。
- 登入後同步課表、帳務與個人財務資料，並支援跨裝置使用。
- 可設定暱稱、搜尋好友、發送與接受好友邀請。
- 未登入時可使用本機模式，資料會儲存在瀏覽器的 Local Storage。
- 支援淺色/深色模式，以及多組主題配色。
- 具備 PWA 安裝支援與 Service Worker 離線快取。

## 快速開始

本專案是無建置步驟的原生 HTML、CSS 與 JavaScript 應用程式，不需要安裝 npm 套件。

### 使用 Python 啟動

請在專案根目錄執行：

```powershell
py -m http.server 5500
```

接著開啟 <http://localhost:5500>。

### 使用 VS Code Live Server

1. 在 VS Code 安裝並啟用 Live Server 擴充功能。
2. 以右鍵點擊 `index.html`。
3. 選擇 **Open with Live Server**。

請使用 HTTP 靜態伺服器，不要直接用 `file://` 開啟 `index.html`。Service Worker、PWA 安裝與部分瀏覽器 API 需要安全來源才能正常運作。

## Supabase 設定

目前 `app.js` 已設定 Supabase 專案 URL 與瀏覽器端公開金鑰，啟動後會嘗試連線至既有後端。若只想使用單機功能，可以不登入；若要使用登入、跨裝置同步、好友與共享帳務，Supabase 專案必須具備對應的 Authentication 與資料表。

程式目前使用的主要資料表如下：

- `profiles`：使用者 Email 與暱稱。
- `user_schedules`：使用者的課表、帳務與財務狀態資料。
- `connections`：好友連線與邀請狀態。
- `user_messages`：好友請求、通知與課表留言。

部署自己的 Supabase 專案時，請一併確認 Row Level Security（RLS）政策只允許使用者存取自己或經授權共享的資料。不要把 Supabase `service_role` 金鑰放進前端；瀏覽器端只能使用公開的 anon/publishable key。

## 資料儲存與離線行為

- 未登入資料儲存在瀏覽器 Local Storage 的 `local_schedule_v2_data`。
- 登入後會先保留本機資料，再透過 Supabase 讀取與寫入雲端資料。
- Service Worker 使用網路優先策略：網路可用時取得最新前端資源，網路失敗時改用快取。
- Supabase API 請求不會由 Service Worker 快取，因此離線時無法進行登入、好友操作或雲端同步。
- 清除瀏覽器網站資料會刪除未同步的本機資料，操作前請確認已登入並完成同步。

## PWA 安裝

使用支援 PWA 的瀏覽器以 HTTP 或 HTTPS 開啟應用程式，待 Service Worker 完成註冊後，即可從瀏覽器的「安裝應用程式」或「加入主畫面」選項安裝。`manifest.json` 也提供「新增記帳」與「查看課表」兩個捷徑。

## 專案結構

```text
.
├── index.html       # 應用程式頁面與各個 Modal
├── app.js           # 狀態管理、畫面渲染、資料同步與互動邏輯
├── style.css        # 主要版面與元件樣式
├── themes.css       # 淺色與深色主題變數
├── manifest.json    # PWA metadata、圖示與捷徑
├── sw.js            # Service Worker 與前端資源快取
└── fonts/           # 應用程式使用的字型資源
```

## 注意事項

- 第一次使用建議先建立一個測試帳號，確認同步與好友權限設定後再放入正式資料。
- 修改前端檔案後，若瀏覽器仍顯示舊版，請重新整理頁面；必要時可在開發者工具中清除 Service Worker 快取。
- Supabase 連線需要網路；本機模式只能在同一個瀏覽器與裝置中保存資料。
- 本專案目前沒有自動化測試或套件鎖定檔，修改後建議至少用桌面與手機尺寸各操作一次主要流程。
